# Health v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Health v2.0.0 as one release. That means:
- Honest, evening-first logging.
- Places and status.
- Training quality (form, clean reps, challenges, readiness).
- A body model that learns.
- The Walk as its own illustrated tab.
- Moments and seasons.
- Last.fm, Logbook and Claude connections.
- Audit data.
- All of it in the Dusk Strata visual world.

**Architecture:**
- Same stack and layering as today.
- Pure rules live in `src/domain` and are tested in Vitest. Persistence lives in `src/db`. Screens, sheets and UI components live in `src/screens`, `src/sheets` and `src/ui`.
- New optional fields go on existing records. New tables arrive in one Dexie version bump (v3) with a migration.
- Personal values arrive only through `private/health-starter.json`.
- The look is built from one token system, `src/styles/tokens.css`, plus an illustration module, `src/walk/art/`, that draws layered vector scenes.

**Tech Stack:** Vite 8, React 19, TypeScript 7, Dexie 4 (+ dexie-react-hooks), vite-plugin-pwa, Vitest 5 with fake-indexeddb. Fonts are the bundled Fraunces, DM Sans and DM Mono (kept by the owner's choice).

**Spec:** `docs/superpowers/specs/2026-10-12-health-v2-design.md`. Sections are referenced as §n.

**Folds in:** the 1.1 plan (`2026-10-12-health-1-1-honest-data.md`). Its Tasks 1–10 become Package A and Package C here. Use this plan, not that one.

**Design contract:** `.impeccable/surfaces/src-app-tsx.md` (Dusk Strata, seed ed131b30). Read it before any UI task, together with `C:/Users/sanya/.claude/skills/impeccable/reference/craft-floor.md`.

## Global Constraints
- **Public repo.** No personal values in `src/`, `tests/`, `docs/` or `public/`: places, meal times, checklist names, setup, body numbers, birth year, reveal date, Last.fm key. Tests use invented fixtures.
- **New fields are optional.** Every 1.x backup restores. A v2 backup restored into 1.x loses only the v2-only tables.
- **Ground rules:**
  - No server, no account, no notifications (in-app banners only), no logging streak.
  - Nothing rewards eating less, and humour never targets body or food.
  - A joint flag switches to plain speech.
  - Four sessions a week, with no extra credit.
- **Outside the phone:**
  - Last.fm and Open Food Facts are the only network calls, and only when online.
  - Speech-to-text is not used.
  - Everything else works offline.
- **Thresholds and constants** (from the spec):
  - Large portion: more than 800 kcal. Impossible value: more than 900 kcal per 100 g or 100 ml.
  - A late tick: more than 120 min after the planned time. The protein gap helper switches to Close the day from 22:00.
  - Office or Trip days: `stepsGoal(t, true)`.
  - Battery saver turns on below 30%.
  - Lighter week: every 6 weeks, or when readiness is low (below 60) two sessions running.
  - Form gate: the previous session's working sets have form 4 or more and RIR 1 or more.
  - Maintenance holds below 10 logged days or 4 weigh-ins in a 28-day window.
  - Tissue energy: fat 9,440 kcal/kg, lean 1,820 kcal/kg. Forbes C = 2.0 kg.
  - The usage log keeps 400 days.
  - Shake is ignored for 5 s after logging a set and during rest.
- **Copy** is plain in data prompts and confirmations. The Gremlin voice appears only on empty states, after saves and in moments.
- **The UI floor:**
  - WCAG AA contrast.
  - 44 px targets.
  - `prefers-reduced-motion` respected by every animation.
  - No `window.confirm`, `alert` or `prompt`.
  - Run the impeccable detector once per package over changed UI.
- **Day boundary:** 4 am. `dayOfLogging` and every "today" use it (spec §1a). Tests in A2 cover 03:59 vs 04:00.
- **Mid-day place changes:** `Day.placeChanges?: { at: number; place: string }[]`; `placeFor(day, settings, at?)` resolves the place at a time (D1).
- **Day closed summary:** C8 adds `src/screens/DayClosed.tsx` and `daySummary(day, entries, sessions, ...)`.
- **Version:** `package.json` 2.0.0. Data contract: `health-plan` v2.
- **Process:**
  - Every task follows TDD (write failing tests, run them, implement, run them, commit).
  - Commit messages are prefixed `feat(v2):` and end with the attribution line.
  - Execution is native: one session builds, and one whole-branch review happens at the end.
  - Run `npm test` and `npm run build` at the end of every package.

## Review Focus
1. **Logging across midnight and for past days.** `eatenAt`, checklist ticks, sleep and steps logged at 00:30 for "yesterday", or with the date chip for three days ago, all land on the chosen date. Tests are in A2, C1 and C4.
2. **Partial data everywhere.** None of the following shows `NaN`, `0` or a crash; each says "not enough data yet":
   - A day with only steps.
   - A week with no food.
   - An exercise whose every set was skipped.
   - A forecast with no history.
   - Maintenance with 3 weigh-ins.
   - Readiness with no morning log.
   - The Walk on day 1.

   Tests are in C5, F2, F6, G1, G4 and H1.
3. **The 1.x to 2.0 migration with real data shapes.**
   - Old `home` values become places.
   - Plan v1 becomes v2 (band moves, `seconds` on carries).
   - Occasions become statuses.
   - The water and retired achievements are hidden but kept.
   - Restoring an old backup after the migration re-runs it.

   The test in A1 uses a fixture shaped like the owner's data, with invented values.
4. **Time-of-day and timezone edges.** The lighting and palette for 23:59 vs 00:01, a session that crosses midnight, the Monday banner on a Sunday-night session, and IST offsets in `Date` math. Tests are in B1, F5 and I3.
5. **Low battery with the screen off mid-rest.**
   - On return, the rest shows "ended N ago".
   - Lifting and rest spans stay consistent, and the wake lock is re-acquired.
   - Without `getBattery`, it falls back to the manual switch.

   Tests are in E4.
