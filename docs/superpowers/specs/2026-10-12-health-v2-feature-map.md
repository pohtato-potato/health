# Health v2: feature map (v1 → v2)

Every v1 feature, what the owner decided about it on the feature board (12 Oct 2026), and where it lives in the v2 layout. Mockups and the build follow this table.

**How to keep it current:** when a feature moves, is cut, or is added, update this table in the same commit as the spec.

**Tabs:** Today · Train · + · Walk · You. "Tracks" is a list inside You that holds every measure page, including Training, Joints and Readiness.
